# DSMS University Website

This repository contains the front-end source for a university website created using [Wix Studio](https://www.wix.com/studio), a no-code web development platform. The website showcases core pages such as Home, Library, Canteen, Hostels, and Campus Life.

## 🌐 Live Site
Visit the live site: [malaypandeygoodboy.wixstudio.com/my-site](https://malaypandeygoodboy.wixstudio.com/my-site)

## 🛠️ Built With

- **Wix Studio** – Development platform for building professional websites
- **HTML / CSS** – For web structure and styling
- **Wix Site Builder Scripts** – Automatically embedded for optimized performance

## 📁 Project Structure

As this site is hosted and managed through Wix, traditional file structures are abstracted. However, key technologies include:

- Meta and SEO configurations
- Webpack runtime bundling
- External CSS 
- Responsive layout optimizations
